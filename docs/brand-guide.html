Why this exists

One Look, Everywhere

PorchFest's colors and type already come from one place — the ink used on the 2026 shirt-print design system, carried into the website's src/index.css tokens and the vector wordmark. This page collects that system in one spot so anyone adding a sponsor page, a social graphic, a flyer, or a new site section can match it without guessing.

Source of truth: the shirt-print ink values — navy #101D3A, flag red #B02A30, warm white #F5F1E6 — plus the true-vector 2026 wordmark. Everything below is either pulled directly from those files or documents how they're already used across the live site.

Mark

The Wordmark

One file: the true-vector 2026 wordmark (src/assets/porchfest-wordmark.svg) — the same hand-drawn art that's on the printed merch. It ships as flag-red letterforms on a warm-white offset shadow, which is why it reads clearly on either ground below without any recoloring. Every instance on this page loads that same file directly, so it can never drift out of sync.

On cream
On navy

Both panels render the identical file — the wordmark carries its own warm-white outline, so it never needs a different asset or a swapped fill per background.

Do

  • Use the SVG straight from src/assets/ at any size — it's vector.
  • Give it breathing room at least equal to the cap-height of "PORCHFEST" on every side.
  • Pair it with the "Senoia" script line above it when there's room for the full lockup.
  • Use the soft flag-red drop shadow only in the hero — it's a one-time flourish, not a default.

Don't

  • Substitute a raster export or a traced copy — always the vector source file.
  • Recolor the mark; it's calibrated for both cream and navy already.
  • Stretch, skew, or rotate it to fit a layout.
  • Drop it directly onto a busy photo without a solid cream or navy panel behind it.

Voice & Formatting

The copy on senoiaporchfest.org is plain and specific — no CMS boilerplate, no marketing fluff. A few conventions repeat everywhere.

Labels & headings
ALL CAPS, Oswald, letter-spaced. Reserved for nav, buttons, and section titles — never for a full sentence.SCHEDULE · VOLUNTEER SIGN-UP · FAQ
Body copy
Sentence case, direct, second person where it helps ("grab a shift"). States facts plainly rather than selling.

Contrast

What Pairs With What

Computed against WCAG 2.1, so "flag-bright is for navy" isn't just a rule of thumb — here's why.

PairingPreviewRatioVerdict
ink on cream Aa 14.8:1 AAA
cream on ink Aa 14.8:1 AAA
pale on ink Aa 11.2:1 AAA
flag on cream Aa 5.8:1 AA
flag-bright on ink Aa 4.7:1 AA
flag (true red) on ink Aa 2.6:1 Fails — use flag-bright

Do

  • Use flag-bright for any red text sitting on navy.
  • Use plain flag for red text and accents on cream or white.
  • Reach for pale for secondary text on navy — it clears AAA.

Don't

  • Put true flag red text directly on ink navy.
  • Introduce a new red or navy shade — the six tokens above cover every case so far.

Tokens live in code, not in this page. Colors and fonts are defined once, in src/index.css as Tailwind @theme variables; the wordmark is src/assets/porchfest-wordmark.svg. Update those, then this guide, together.
